# 갈래? 말래? 최종 게임 로직

> Java Swing과 TCP 소켓으로 구현하는 2인 맞고 게임의 최종 규칙 설계서  
> 팀: **갈래말래** · 프로젝트: **갈래? 말래?**  
> 기준일: 2026년 11월 12일

## 1. 문서 상태와 프로젝트 기준

- 이 문서는 팀 대화에서 확정한 게임 규칙과 서버 처리 기준을 정리한 문서이다. 2026-11-24에 분배 전 퇴장 규칙과 로직 구현 상태를 갱신했다.
- Java 게임 로직은 `갈래말래_로직테스트/step8-전체게임로직`에 구현했다. 로직 자체 검사는 해당 폴더의 `FullGameCheck`로 실행한다. 이번 변경에서는 Swing·TCP·JSON 연결을 하지 않았으며, 최종 로직과 UI·서버의 연동 및 2인 통합 검사는 **추후 진행**한다.
- README의 `서비스패 3장`, `방장이 시작`이라는 설명은 최종 규칙과 다르다. 각각 `서비스패 2장`, `두 플레이어 모두 준비 완료 시 시작`으로 수정해야 한다.

| 항목 | 확정값 |
| --- | --- |
| 게임 방식 | 게임방별 2인 맞고 |
| 덱 | 기본 화투 48장 + 서비스패 2장 = 50장 |
| 서비스패 | 2점 서비스패 1장, 3점 서비스패 1장 |
| 시작 게임머니 | 1인당 1,000,000원 |
| 기본 정산 단가 | 1점당 10,000원 |
| 최초 고·스톱 기준 | 기본 점수 7점 |
| 행동 제한 시간 | 각 선택 요청마다 30초 |

서버가 손패, 바닥패, 더미패, 획득패, 차례, 점수, 배율 및 게임머니의 단일 원본이다. 클라이언트는 행동 요청을 보내고 서버의 확정 결과를 표시하며 상대 손패는 전달받지 않는다.

## 2. 전체 진행 순서

```text
방 생성·입장
→ 두 플레이어 준비 완료
→ 새로운 대결이면 선 결정
→ 덱 생성·섞기·패 분배
→ 초기 서비스패 및 총통 검사
→ 선부터 턴 반복
→ 매칭·특수 규칙·점수 계산
→ 고 또는 스톱
→ 정상 정산·나가리·특수 종료
→ 다음 판 준비 또는 퇴장
```

### 준비 상태

1. 준비 버튼을 누른 플레이어만 `준비 완료`가 된다.
2. 두 플레이어가 모두 준비 완료일 때 서버가 판을 시작한다.
3. 패 분배 전에는 준비를 취소하거나 패널티 없이 방을 나갈 수 있다.
4. 판 종료 후 양쪽 준비 상태는 다시 `준비 안 됨`으로 초기화한다.
5. 두 명 모두 준비된 뒤 서버가 패 분배를 시작한 순간부터 `게임 진행 중`이다.

## 3. 선 결정

### 새로운 대결

1. 서버가 기본 화투 48장 중 5장을 무작위로 공개한다.
2. 두 플레이어에게 동시에 30초의 선택 시간을 준다.
3. 서로 다른 패를 고르면 두 선택을 확정한다.
4. 같은 패를 골랐다면 서버에 유효한 요청이 먼저 도착한 플레이어가 그 패를 차지한다.
5. 늦게 도착한 요청은 거절하고 남은 4장 중 다시 고르게 하며, 재선택에는 새로운 30초를 준다.
6. 두 선택이 확정되기 전에는 상대가 고른 패를 공개하지 않는다.
7. 선택한 패의 월이 높은 플레이어가 선이다.
8. 월이 같으면 `광 → 열끗 → 띠 → 피` 순서로 비교한다.
9. 월과 종류까지 같으면 다시 추첨한다.
10. 선 결정에 쓴 패는 실제 덱에서 제거하지 않고 48장에 다시 포함해 섞는다.
11. 선결정은 패 분배 전 단계이다. 이때 퇴장하거나 30초가 지나면 금액 차감 없이 퇴장 처리한다. 상대는 새 플레이어를 기다린다. 두 사람 모두 남아 있는 동안 준비를 취소하면 선결정을 취소하고 준비 대기로 돌아간다.

서버 도착 순서가 우선순위 기준이다. 클라이언트가 표시한 클릭 시각은 사용하지 않는다.

### 다음 판의 선

| 이전 판 결과 | 다음 판 |
| --- | --- |
| 정상 승리 | 승자가 선 |
| 3뻑·총통 승리 | 해당 승자가 선 |
| 나가리 | 기존 선 유지 |
| 동시 총통 무효 | 기존 선 유지 |

기권 등으로 상대가 나간 뒤 새 플레이어가 들어오면 새로운 대결이므로 선 결정부터 다시 진행한다.

## 4. 덱과 패 분배

### 덱 구성

| 구분 | 장수 | 처리 |
| --- | :---: | --- |
| 기본 화투 | 48장 | 월·종류에 따라 점수 계산 |
| 2점 서비스패 | 1장 | 유효 피 2장 |
| 3점 서비스패 | 1장 | 유효 피 3장 |
| 합계 | 50장 |  |

### 분배 순서

다음 순서를 두 번 반복한다.

```text
바닥 4장 → 상대 5장 → 선 5장
```

최초 분배 결과는 선과 상대의 손패 각 10장, 바닥패 8장, 더미패 22장이다. 서버는 카드 ID 중복과 전체 50장 보존 여부를 검사한다.

### 초기 바닥 서비스패

1. 바닥에 서비스패가 있으면 선이 즉시 획득한다.
2. 제거한 수만큼 더미에서 바닥패를 보충한다.
3. 보충한 패도 서비스패면 선이 획득하고 다시 보충한다.
4. 정상 월 패 8장이 될 때까지 반복한다.
5. 이 단계에서는 상대 피를 가져오지 않는다.
6. 보충이 끝난 최종 바닥패 8장을 기준으로 같은 월 패와 바닥 총통을 검사한다.

### 초기 같은 월 패

- 같은 월 3장: 겹쳐 표시하고 정상 진행한다.
- 같은 월 4장: 선의 바닥 총통 승리로 즉시 종료한다.

## 5. 총통

### 조건

- 손패 총통: 최초 손패에 같은 월 패 4장이 모두 있는 경우
- 바닥 총통: 초기 서비스패 보충 후 바닥에 같은 월 패 4장이 있는 경우이며 선의 총통으로 본다.

### 처리

- 일반 턴 전에 서버가 판정하고 한 플레이어만 총통이면 즉시 승리한다.
- 고정 10점, 즉 100,000원을 기준으로 정산한다.
- 고·역고·박·흔들기·폭탄·나가리 등 모든 배율을 적용하지 않는다.
- 정상 승리이므로 나가리 누적값을 초기화하고 승자가 다음 판의 선이 된다.

### 충돌

- 두 플레이어가 각각 손패 총통이면 해당 판은 무효이다.
- 바닥 총통으로 선도 총통이고 상대도 손패 총통이면 양쪽 총통이므로 무효이다.
- 선에게 손패 총통과 바닥 총통이 함께 생기고 상대는 총통이 아니면 선의 단일 승리이며 중복 지급하지 않는다.
- 무효 판은 정산하거나 나가리 횟수를 추가하지 않는다.
- 기존 선과 판 시작 전 나가리 배율을 유지한 채 다시 섞어 재분배한다.

## 6. 한 턴의 처리 순서

```text
턴 시작·30초 타이머
→ 선택적 손패 서비스패 사용
→ 정상 손패 제출 또는 폭탄 뒤집기 기회 사용
→ 손패 매칭 및 필요한 대상 선택
→ 더미패 공개·서비스패 처리·매칭
→ 특수 규칙 판정
→ 획득패 이동
→ 쓸 판정
→ 피 가져오기 합산·이동
→ 기본 점수 계산
→ 즉시 종료 또는 고·스톱 판정
→ 상태 버전 증가 및 결과 전송
```

## 7. 기본 매칭

손패를 낼 때와 더미패를 공개할 때 각각 바닥의 같은 월 패 수를 확인한다.

| 바닥의 같은 월 패 | 처리 |
| :---: | --- |
| 0장 | 낸 패 또는 공개한 패를 바닥에 놓음 |
| 1장 | 두 패를 매칭하여 획득 |
| 2장 | 획득할 바닥패 한 장을 플레이어가 선택 |
| 3장 | 같은 월 4장을 모두 획득 |

- 바닥에 매칭되는 패가 없어도 자신의 정상 월 패 중 원하는 패를 낼 수 있다.
- 같은 월 2장에서 선택이 필요하면 서버는 선택 가능한 카드 ID만 전달한다.
- 선택에도 30초 제한을 적용하며 잘못된 선택은 거절하고 기존 타이머는 계속 흐른다.

## 8. 서비스패

### 공통

- 2점 서비스패는 유효 피 2장, 3점 서비스패는 유효 피 3장이다.
- 월이 없으므로 일반 월 패와 매칭하지 않는다.

### 손패에서 사용

1. 서비스패를 사용하면 즉시 자신의 획득패가 된다.
2. 상대의 획득패 영역에서 피 카드 1장을 가져온다.
3. 더미 맨 위 패 1장을 자신의 손패로 가져온다.
4. 가져온 패가 서비스패면 먼저 손패에 넣는다.
5. 플레이어는 새 서비스패를 즉시 이어서 사용하거나, 손에 보관하고 다른 정상 월 패를 낼 수 있다.
6. 손패에 새 서비스패밖에 없다면 그 서비스패를 사용해야 한다.
7. 서비스패를 다시 사용하면 서비스패 획득, 피 1장 이동, 더미패 한 장을 손으로 가져오는 효과를 다시 적용한다.
8. 최종적으로 정상 월 패 한 장을 낸 뒤 일반 더미 공개 단계까지 진행한다.

더미가 이미 비어 있으면 더 이상 패를 가져오지 않는다. 손에 정상 월 패가 있으면 내고, 낼 패도 없다면 가능한 효과까지만 반영한 뒤 종료 조건을 검사한다.

### 더미에서 공개

1. 현재 턴 플레이어가 즉시 획득한다.
2. 상대 획득패에서 피 카드 1장을 가져온다.
3. 정상 월 패가 나올 때까지 더미를 계속 공개한다.
4. 서비스패가 연속되면 각 서비스패 효과를 각각 적용한다.
5. 더미가 소진되면 추가 공개를 중단하고 종료 조건을 검사한다.

## 9. 피 가져오기

`상대 피 1장을 가져온다`는 것은 상대 손패가 아니라 **상대가 이미 획득해 공개해 둔 획득패 영역**에서 피 카드를 가져온다는 뜻이다.

서버는 다음 순서로 자동 선택한다.

1. 일반 피
2. 쌍피
3. 2점 서비스패
4. 3점 서비스패

- 피 2장 이상도 이 순서를 한 장씩 반복한다.
- 상대 피가 부족하면 가능한 수량만 가져오고, 없으면 0장으로 끝낸다.
- 쌍피나 서비스패도 물리적인 카드 한 장을 이동하며, 새 소유자의 점수에는 해당 환산값을 적용한다.
- 상대가 줄 카드를 직접 선택하지 않는다.

복합 사건은 피 이동 수를 합산한다.

| 동시 발생 | 가져오는 피 카드 수 |
| --- | :---: |
| 따닥 + 쓸 | 2장 |
| 쪽 + 쓸 | 2장 |
| 상대 뻑 획득 + 쓸 | 2장 |
| 자뻑 + 쓸 | 3장 |

판정 순서는 `매칭·특수 사건 확정 → 획득패 이동 → 바닥이 비었는지 검사 → 쓸 추가 → 총 피 이동 수 합산`이다.

## 10. 특수 규칙

### 뻑

손패로 바닥패 한 장을 매칭한 뒤 더미에서도 같은 월 패가 나와 같은 월 3장이 겹치는 상황이다.

- 첫 번째와 두 번째 뻑 때 돈이나 피를 즉시 지급하지 않는다.
- 뻑을 만든 플레이어의 개인 뻑 횟수만 1씩 증가한다.
- 같은 월 3장은 바닥에 겹쳐 둔다.
- 나중에 누가 먹더라도 만든 사람의 누적 횟수는 유지한다.
- 연속된 턴이 아니어도 한 판 안에서 누적한다.

자신이 만든 뻑을 먹으면 **자뻑**으로 상대 피 카드 2장을 가져온다. 상대가 만든 뻑을 먹으면 상대 피 카드 1장을 가져온다.

#### 3뻑

- 한 플레이어가 한 판에서 직접 만든 뻑이 누적 3회가 되는 순간 즉시 승리한다.
- 상대 뻑을 먹은 것은 자신의 뻑 횟수에 포함하지 않는다.
- 세 번째 뻑 이후 남은 처리나 고·스톱 선택 없이 종료한다.
- 고정 10점, 즉 100,000원을 기준으로 하며 모든 배율을 제외한다.
- 정상 승리로 보아 나가리 누적값을 초기화하고 승자가 다음 판의 선이 된다.

### 따닥

바닥에 같은 월 패 2장이 있고, 손패에서 같은 월 패를 낸 뒤 더미에서도 네 번째 같은 월 패가 나오면 4장을 모두 획득하고 상대 피 1장을 가져온다. 이후 바닥이 비면 쓸도 성립하여 총 2장을 가져온다.

### 쪽

손패에서 낸 패와 같은 월의 바닥패가 없어 패를 놓았는데 바로 공개한 더미패가 같은 월이면 두 패를 획득하고 상대 피 1장을 가져온다. 처음부터 바닥이 비어 있었고 쪽으로 다시 비면 쓸까지 성립하여 총 2장을 가져온다.

### 쓸

한 턴의 매칭과 획득이 끝난 뒤 바닥에 남은 패가 없으면 상대 피 1장을 가져온다. 따닥·쪽·자뻑·상대 뻑 획득과 독립적으로 중복 적용한다.

### 흔들기

조건은 손패에 같은 월 패 3장이 있고 바닥에 해당 월 패가 없는 경우이다.

1. 같은 월 3장을 상대에게 공개한다.
2. 세 장 중 한 장을 내기 전에 흔들기를 선언한다.
3. 흔들기 횟수를 1회 증가시킨다.
4. 사용한 플레이어가 승리하면 한 번당 ×2를 적용한다.
5. 흔들기만으로 피를 가져오지 않는다.

### 폭탄

조건은 손패에 같은 월 패 3장이 있고 바닥에 그 월 패가 정확히 1장 있는 경우이다.

1. 손패 3장을 한꺼번에 내서 같은 월 4장을 모두 획득한다.
2. 상대 피 1장을 가져온다.
3. 폭탄 횟수를 1회 증가시키고 사용자가 승리하면 한 번당 ×2를 적용한다.
4. 하나의 폭탄에 흔들기 배율을 중복 적용하지 않는다. 폭탄 한 번은 ×2이다.

#### 폭탄 뒤집기 기회

- 폭탄 한 번당 손패를 내지 않고 더미만 뒤집는 기회 2회를 얻는다.
- 여러 폭탄의 기회는 제한 없이 누적한다. 폭탄 2회면 4회이다.
- 폭탄을 쓴 바로 그 턴이 아니라 이후 자기 차례부터 사용한다.
- 한 차례에는 최대 1회만 사용한다.
- 손패가 있으면 정상 패 제출과 기회 사용 중 선택할 수 있다.
- 손패가 없고 기회가 남았다면 기회를 사용해야 한다.
- 남은 기회는 판 종료 시 소멸한다.
- 기회로 뒤집은 패도 일반 더미처럼 매칭·획득·서비스패·쓸·상대 뻑 획득을 판정한다.
- 손패를 내지 않았으므로 쪽·따닥·새로운 뻑은 발생하지 않는다.

### 반복 배율

```text
흔들기·폭탄 배율 = 2 ^ (흔들기 횟수 + 폭탄 횟수)
```

예를 들어 흔들기 2회는 ×4, 폭탄 2회는 ×4, 흔들기 2회와 폭탄 1회는 ×8이다. 이 배율은 사용한 플레이어가 최종 승리했을 때만 적용한다. 패자가 사용한 배율은 승자의 정산에 영향을 주지 않는다.

## 11. 점수 계산

### 광

| 조합 | 점수 |
| --- | :---: |
| 비광 없는 3광 | 3점 |
| 비광 포함 3광 | 2점 |
| 4광 | 4점 |
| 5광 | 15점 |

### 띠

| 족보 | 구성 | 점수 |
| --- | --- | :---: |
| 홍단 | 1월·2월·3월 홍단 | 3점 |
| 청단 | 6월·9월·10월 청단 | 3점 |
| 초단 | 4월·5월·7월 띠 | 3점 |

- 12월 띠는 초단에 포함하지 않지만 전체 띠 장수에는 포함한다.
- 띠 5장부터 1점, 초과 1장마다 +1점이다.
- 홍단·청단·초단과 띠 장수 점수는 함께 더한다.

### 열끗

- 열끗 5장부터 1점, 초과 1장마다 +1점이다.
- 2월·4월·8월 열끗을 모두 모은 고도리는 5점이다.
- 고도리와 열끗 장수 점수는 함께 더한다.

### 피

- 일반 피 1장, 쌍피 2장, 2점 서비스패 2장, 3점 서비스패 3장으로 환산한다.
- 국진을 쌍피로 확정하면 유효 피 2장이다.
- 유효 피 10장부터 1점, 초과 1장마다 +1점이다.

### 국진

1. 기본적으로 열끗이다.
2. 국진을 쌍피로 바꿨을 때 7점 이상이 되어 고·스톱 조건이 생기는 상황에서는 고·스톱 전에 전환 여부를 선택한다.
3. 쌍피로 확정하면 해당 판에서 다시 열끗으로 바꿀 수 없다.
4. 쌍피 국진은 열끗 장수·고도리·멍박 판정에서 제외하고 유효 피 2장으로만 계산한다.
5. 선택에는 30초 제한을 적용한다.

## 12. 고·스톱

### 최초 선택과 재선택

- 고 보너스를 제외한 기본 점수가 7점 이상이 된 순간 처음 고 또는 스톱을 선택한다.
- 고를 선언한 시점의 기본 점수를 기준점으로 저장한다.
- 이후 획득패와 족보로 계산한 기본 점수가 기준점보다 최소 1점 증가해야 다시 고·스톱을 선택할 수 있다.
- 고 보너스 +1점은 기본 점수 증가로 보지 않는다.
- 기본 점수가 그대로면 선택창 없이 턴을 넘긴다.
- 다시 고를 하면 그 시점의 기본 점수를 새 기준점으로 저장한다.
- 한 번에 여러 점이 올라도 선택 기회는 한 번이다.

### 고 점수와 배율

- 고 한 번마다 최종 정산 점수에 +1점을 더한다.
- 3고부터 고가 하나 늘 때마다 배율이 두 배가 된다.

| 고 횟수 | 고 보너스 | 고 배율 |
| :---: | :---: | :---: |
| 1고 | +1점 | ×1 |
| 2고 | +2점 | ×1 |
| 3고 | +3점 | ×2 |
| 4고 | +4점 | ×4 |
| 5고 | +5점 | ×8 |

3고 이상 일반식은 `2 ^ (고 횟수 - 2)`이다.

### 역고

상대가 먼저 고를 한 상태에서 다른 플레이어도 고를 하면 역고이다. 역고 선언자가 최종 승리했을 때만 ×2를 한 번 적용한다. 역고 선언자가 패배하거나 나가리면 적용하지 않는다.

### 마지막 턴

- 마지막 행동으로 처음 7점에 도달하거나, 이전 고 기준점보다 기본 점수가 1점 이상 올라 다시 고·스톱 조건을 충족했지만 더 진행할 패가 없으면 선택창 없이 정상 승리로 즉시 정산한다.
- 마지막 턴에 고를 선택했다가 패가 없어 나가리가 되는 방식은 사용하지 않는다.
- 이미 고를 했지만 마지막까지 기본 점수가 기준점보다 오르지 못했고 상대도 종료 점수를 만들지 못했다면 나가리이다.
- **2026-11-24 확정:** 두 사람의 손패와 폭탄 기회가 모두 소진되었을 때 더미 맨 아래에 서비스패만 남았다면, 그 서비스패는 획득하지 않고 현재 점수로 종료한다. 잔여 서비스패로 인한 피 이동도 없다.

## 13. 박

### 피박 ×2

승자가 피 계열에서 실제 1점 이상을 얻고 패자의 유효 피가 7장 이하일 때만 적용한다.

### 광박 ×2

승자가 광 조합으로 실제 점수를 얻고 패자가 광을 한 장도 획득하지 못했을 때 적용한다. 비광도 광 보유 장수에는 포함한다.

### 멍박 ×2

승자가 열끗 장수 점수 또는 고도리 점수를 얻고 패자가 열끗을 한 장도 획득하지 못했을 때 적용한다.

### 고박 ×2

패자가 한 번 이상 고를 한 뒤 상대가 스톱 또는 마지막 턴 자동 정산으로 승리하면 적용한다. 고 이후 점수가 오르지 않아 재선택하지 못했어도 이미 고를 했으므로 고박이다.

### 중복

피박·광박·멍박·고박은 독립적으로 곱한다. 네 가지가 모두 성립하면 ×16이며, 승자의 고·역고·흔들기·폭탄 및 나가리 배율과도 곱한다. 고정 정산 종료에는 어떤 박도 적용하지 않는다.

## 14. 나가리

### 조건

- 두 플레이어가 손패와 폭탄 기회를 모두 사용했지만 누구도 정상 종료 조건을 만들지 못한 경우. 더미 맨 아래의 잔여 서비스패는 마지막 턴 규칙에 따라 획득하지 않는다.
- 한 플레이어가 이미 고를 했지만 이후 기본 점수가 기준점보다 1점 이상 오르지 못해 다시 고·스톱을 선택하지 못했고, 상대도 스톱 가능한 점수를 만들지 못한 채 패가 소진된 경우

### 처리

- 해당 판은 승패와 금액 정산이 없다.
- 기존 선이 다음 판에도 선이다.
- 다음 판에 ×2를 적용하고 연속 나가리마다 누적한다.

```text
나가리 배율 = 2 ^ 연속 나가리 횟수
```

정상 승리, 총통, 3뻑 또는 기권패로 끝나면 누적 나가리 횟수와 배율을 ×1로 초기화한다. 동시 총통 무효는 기존 나가리 배율을 유지한다.

## 15. 정산

### 일반 승리

```text
정산 점수 = 기본 점수 + 고 횟수
계산된 정산금 = 정산 점수 × 10,000원 × 모든 적용 배율
```

적용 가능한 배율은 3고 이상 고 배율, 역고, 승자의 흔들기·폭탄, 현재 판의 나가리 누적 배율, 피박·광박·멍박·고박이며 모두 곱한다.

### 획득 금액 상한

점수와 고가 아무리 높아도 승자는 자신이 가진 돈을 초과해서 딸 수 없고, 패자도 가진 돈보다 많이 잃을 수 없다.

```text
실제 지급액 = min(
  계산된 정산금,
  승자의 판 시작 시 보유 금액,
  패자의 정산 직전 보유 금액
)
```

예를 들어 승자가 판 시작 시 100,000원을 가졌다면 계산 금액이 1,000,000원이어도 최대 100,000원만 받는다. 패자가 50,000원만 가졌다면 실제 지급액은 50,000원이다. 잔액은 음수가 될 수 없다.

### 고정 정산

| 종료 사유 | 기준 | 배율 |
| --- | --- | --- |
| 총통 | 고정 10점 = 100,000원 | 적용 안 함 |
| 3뻑 | 고정 10점 = 100,000원 | 적용 안 함 |
| 기권·연결 종료·시간 초과 | 고정 100,000원 | 적용 안 함 |

고정 정산에도 승자의 판 시작 금액과 패자의 현재 금액 상한을 동일하게 적용한다.

### 파산

- 정산 후 잔액이 0원이면 파산으로 자동 퇴장한다.
- 정상 승부 정산으로 한 명이 파산하면 대결을 종료하고 남은 플레이어는 대기실로 이동한다.
- 서버가 실제 지급액과 적용 근거를 양쪽에 동일하게 전송한다.

## 16. 연결 종료·퇴장·시간 제한

### 진행 중 퇴장

- 판 진행 중 연결 종료, 퇴장 버튼, 창 닫기는 즉시 기권패이다.
- 재접속 대기 시간은 없다.
- 기권자는 고정 100,000원에 보유 금액 상한을 적용해 지급하고 강제 퇴장한다.
- 승자는 같은 게임방에 남아 새로운 상대를 기다린다.
- 이전 판 상태와 나가리 누적값은 초기화한다.

상대가 없거나 패 분배 전인 준비·선결정 단계에서는 패널티 없이 방을 나갈 수 있다. 상대 없는 대기에는 제한 시간이 없다. 선결정 선택에는 30초 제한이 있지만, 초과 시에도 금액 차감 없이 퇴장한다. **기권 정산의 시작 경계는 패 분배이다.**

### 30초 제한

손패 제출, 같은 월 2장 중 대상 선택, 고·스톱, 국진 전환, 폭탄 기회 등 서버가 요구하는 모든 진행 선택에 적용한다.

1. 서버가 선택 요청을 보낸 순간부터 측정한다.
2. 손패에 없는 패, 이미 사용한 패, 차례가 아닌 행동 등은 수행하지 않는다.
3. 잘못된 요청으로 상태를 바꾸거나 타이머를 초기화·연장하지 않는다.
4. 서버는 거절 사유와 남은 시간을 알려 준다.
5. 패 분배 후 30초 안에 정상 행동을 완료하지 않으면 즉시 기권패, 고정 100,000원 정산 및 강제 퇴장이다. 분배 전 선결정 시간 초과는 위의 무료 퇴장 규칙을 따른다.
6. 서버가 자동으로 패를 대신 내거나 턴만 넘기지 않는다.

## 18. 서버 검증과 예외 처리

서버는 매 요청마다 참가자·차례·카드 소유권·허용된 선택 후보·고 및 특수 규칙 조건·판 번호·상태 버전·방 진행 상태를 검사한다.

- 각 요청에는 고유 요청 ID와 기대 상태 버전을 둔다.
- 같은 요청은 한 번만 처리한다.
- 늦게 도착한 이전 버전 요청은 거절하고 최신 공개 상태를 다시 보낸다.
- 상태가 바뀔 때마다 서버 상태 버전을 증가시킨다.
- 카드 중복, 전체 장수 불일치 등 정상 규칙으로 발생할 수 없는 내부 오류가 발견되면 진행과 정산을 중단한다.
- 내부 오류 판은 무효 처리하고 로그를 남기며, 기존 선과 판 시작 전 나가리 배율을 유지한 채 준비 상태로 돌린다.
